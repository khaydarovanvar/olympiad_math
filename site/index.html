How to use it

A study path that finishes problems

Reading theory is the easy half. This is the loop that turns a topic you have read into a topic you can score on.

Read one theory source

Start with the starred resource on the topic page. One good source beaten thoroughly is worth five skimmed.

Watch the hard idea

When a proof will not sit still, the video column exists for exactly that step — not for the whole topic.

Work twenty problems

Easy to hard, written out in full. A problem you can only start is a problem you cannot yet do.

Sit a past paper

Mathnet.uz and the past-paper PDFs are in every topic. Time yourself; mark yourself honestly.

Complete theory with every proof, worked examples and graded competition problems — divisibility, inequalities and geometry, ready to teach from.
